# ROVA ONE

A polished, responsive product landing page and ordering experience for a fictional digital smartwatch brand.

ROVA ONE was built as a portfolio project to demonstrate modern React development, responsive UI design, component-based architecture, animation, and a complete product-to-order user flow.

## 🌐 Live Demo

**[View ROVA ONE](https://sheras-art.github.io/ROVA-one/)**

**Status:** ✅ Completed — Portfolio Project

---

## ✨ Overview

ROVA ONE is a premium digital smartwatch experience designed around a dark, high-contrast visual identity with a distinctive lime accent.

The project goes beyond a simple landing page by providing a complete user journey:

**Product Landing Page → Product Information → Order Form → Order Confirmation**

The interface is fully responsive and designed to provide a consistent experience across desktop, tablet, and mobile devices.

> **Note:** ROVA ONE is a fictional portfolio project and is not an actual smartwatch store or commercial product.

## 🎨 Design

ROVA ONE uses a dark, premium visual direction built around a small set of reusable design tokens.

### Design characteristics

* Dark UI
* High-contrast typography
* Lime accent color
* Large product imagery
* Clean spacing and visual hierarchy
* Subtle motion and transitions
* Responsive component layouts

The project uses centralized CSS variables for colors, typography, borders, spacing, and other reusable design values to maintain visual consistency throughout the application.

---

## 📱 Responsive Design

ROVA ONE is designed to adapt across different screen sizes, including:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop

The responsive navigation progressively adapts to available screen width, while content sections, typography, imagery, and layouts adjust to maintain usability and visual balance.

The application was also tested on physical mobile devices to verify the responsive experience and prevent common issues such as horizontal overflow and clipped content.

---

## 🛒 Order Flow

The project includes a dedicated ordering experience rather than stopping at the landing page.

### User flow

1. Explore the ROVA ONE product
2. Click **Buy Now**
3. Navigate to the order page
4. Enter delivery and payment information
5. Select a payment method
6. Complete the order form
7. Submit the order
8. View the final confirmation page

The final confirmation screen also makes it clear that the experience is part of a portfolio project.

## 🧩 Project Structure

The application follows a component-based React structure to keep the interface modular and maintainable.

```text
src/
├── assets/
├── components/
├── hooks/
├── pages/
├── styles/
├── App.jsx
└── main.jsx
```

The project separates reusable UI components, pages, hooks, assets, and styling to keep responsibilities organized as the application grows.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/sheras-art/ROVA-one.git
```

Navigate into the project:

```bash
cd ROVA-one
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL, typically:

```text
http://localhost:5173
```

---

## 📦 Production Build

To create a production build:

```bash
npm run build
```

The optimized production files will be generated in the `dist` directory.

To preview the production build locally:

```bash
npm run preview
```
