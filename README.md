# ROVA ONE

ROVA ONE is a modern smart fitness watch landing page built as a portfolio project to demonstrate frontend development, responsive design, and interactive UI implementation.

## Tech Stack

- React
- Vite
- JavaScript
- CSS Modules
- React Router
- Lucide React

## Features

- Responsive landing page
- Product-focused Hero section
- Responsive navigation
- Product highlights and feature sections
- Interactive CTA and order flow
- Responsive design across screen sizes
- Modern glassmorphism and visual effects

## Purpose

This project was created to demonstrate practical frontend development skills through a realistic product landing page and ordering experience.
